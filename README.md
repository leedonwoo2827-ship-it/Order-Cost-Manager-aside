# 수주 및 비용 통합 관리 프로그램

HRD 훈련내역, 계산서 발행내역, 입금내역을 엑셀 파일로 불러와 거래처/입금자 매핑을 자동으로 수행하고, 정산용 DATA 시트와 입금-계산서 대조표를 만드는 로컬 웹 프로그램입니다.

## 빠른 실행

Windows에서 프로젝트 폴더의 `run-local.bat`을 더블클릭한 뒤 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:3000
```

자세한 프로젝트 요약과 사용 방법은 [PROJECT_GUIDE.md](./PROJECT_GUIDE.md)를 참고하세요.

## 어사이드 비용신청 (이 포크에서 추가)

대시보드 **통합 DATA** 화면의 `HRD-Net 비용신청 올리기` 버튼 하나로 진행합니다.

1. 수금 확인된 회차가 증빙(수납확인서 PDF)과 함께 `rpa` 엔진의 inbox로 내보내집니다. 전자계산서 PDF는 `증빙` 폴더에 직접 넣습니다.
2. 오른쪽에 사이드 패널이 열리고, 왼쪽 HRD-Net 설치 프로그램을 pywinauto로 조작합니다. 로그인·인증서는 사람이 합니다.
3. 최종 `[훈련비용 신청]`은 회차마다 패널에서 사람이 누릅니다.
4. 끝나면 `결과 반영` 버튼으로 비용신청여부를 일괄 체크합니다.

엔진 설치·사용: `rpa/run.bat` (처음 실행 시 가상환경과 패키지를 자동 설치). 원본: hyunjinjb2b/Order-Cost-Manager.
