# 수주 및 비용 통합 관리 프로그램 (어사이드 비용신청 포크)

HRD 훈련내역, 계산서 발행내역, 입금내역을 엑셀 파일로 불러와 거래처/입금자 매핑을 자동으로 수행하고, 정산용 DATA 시트와 입금-계산서 대조표를 만드는 프로그램입니다.
이 포크는 여기에 **HRD-Net 비용신청 자동화**(설치 프로그램을 pywinauto로 조작)와 **백업 보관함**을 더했습니다. 원본: hyunjinjb2b/Order-Cost-Manager

## 빠른 설치 · 실행

미리 설치할 것: **Node.js 22 LTS**, **Python 3.12**(설치 첫 화면에서 "Add python.exe to PATH" 체크), Chrome 또는 Edge

| 순서 | 할 일 | 언제 |
|---|---|---|
| 1 | 폴더를 받는다 (`git clone` 또는 Code → Download ZIP 후 압축 풀기) | 처음 한 번 |
| 2 | **`setup.bat`** 더블클릭 — 대시보드 설치, 빌드, RPA 엔진 설치까지 한 번에 (5~10분) | 처음 한 번 |
| 3 | **`run.bat`** 더블클릭 — 대시보드가 열린다. 검은 창은 닫지 말고 최소화 | 평소 |

- `run.bat`은 설치가 안 돼 있으면 `setup.bat`을 먼저 자동으로 돌립니다.
- 업데이트: `git pull` 후 `setup.bat`을 다시 한 번 실행합니다.
- 엔진·패널은 대시보드의 **「사이드 패널 열기」** 버튼이 알아서 켭니다.

## 어사이드 비용신청 (이 포크에서 추가)

1. 대시보드 **「통합 DATA 시트」**에서 평소처럼 수금까지 확인합니다.
2. **「HRD-Net 비용신청 올리기」**를 누르면 수금 확인된 회차가 수납확인서 PDF와 함께 `rpa` 엔진의 inbox로 내보내집니다. 전자계산서 PDF는 `증빙` 폴더에 직접 넣습니다.
3. **「HRD-Net 비용신청」 탭**에서 「▶ 정리」 → 회차 선택 → 모의 실행 / 점검 / 미리 채워 보기 / 신청을 실행합니다. 진행은 오른쪽 사이드 패널에 나옵니다.
4. 로그인·인증서와 마지막 `[훈련비용 신청]`은 사람이 합니다. 최종 신청은 회차마다 패널에서 확인합니다.
5. **「4 결과표」**로 결과를 만들고, 대시보드의 **「결과 반영」**으로 비용신청여부를 일괄 체크합니다.
6. **「백업·정리」**로 끝난 회차를 백업 폴더로 옮기고, 탭 아래 **「백업 보관함」**에서 목록을 봅니다. 보관 기간(기본 90일)이 지난 백업은 자동 삭제되며, `archive_root`를 정하면 장기 보관처로 복사가 끝난 것만 삭제됩니다.

설정은 `rpa/local.json`(처음 켜면 자동 생성)에서 바꿉니다: `data_root`, `backup_root`, `backup_keep_days`, `archive_root`, `hrdnet_exe`.

## 참고
- 원본 프로그램의 자세한 설명: [PROJECT_GUIDE.md](./PROJECT_GUIDE.md) (원본 작성자 문서. 실행 방법은 위 설명이 최신입니다)
- 데이터(수금 확인, 직접 수정한 값)는 프로그램마다 따로 저장됩니다. 원본 프로그램과 같은 PC에 깔아도 서로 공유되지 않습니다.
- HRD-Net 화면 조작(`rpa/steps.yaml`의 버튼 정보)은 HRD-Net이 설치된 PC에서 한 번 맞춰야 합니다.
