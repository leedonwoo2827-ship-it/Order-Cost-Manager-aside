# 수주 및 비용 통합 관리 프로그램 (어사이드 비용신청 포크)

HRD 훈련내역, 계산서 발행내역, 입금내역을 엑셀 파일로 불러와 거래처/입금자 매핑을 자동으로 수행하고, 정산용 DATA 시트와 입금-계산서 대조표를 만드는 프로그램입니다.
이 포크는 여기에 **HRD-Net 비용신청 자동화**(설치 프로그램을 pywinauto로 조작)와 **백업 보관함**을 더했습니다. 원본: hyunjinjb2b/Order-Cost-Manager

## 빠른 설치 · 실행

미리 설치할 것: **Node.js 22 LTS**, **Python 3.12**(설치 첫 화면에서 "Add python.exe to PATH" 체크), Chrome 또는 Edge

| 순서 | 할 일 | 언제 |
|---|---|---|
| 1 | 폴더를 받는다 (`git clone` 또는 Code → Download ZIP 후 압축 풀기) | 처음 한 번 |
| 2 | **`setup.bat`** 더블클릭 — 대시보드 설치, 빌드, RPA 엔진 설치까지 한 번에 (5~10분) | 처음 한 번 |
| 3 | **`run.bat`** 더블클릭 — 대시보드가 열린다. 검은 창은 닫지 말고 최소화 | 평소 |

- `run.bat`은 설치가 안 돼 있으면 `setup.bat`을 먼저 자동으로 돌립니다.
- 업데이트: `git pull` 후 `setup.bat`을 다시 한 번 실행합니다.
- 엔진·패널은 대시보드의 **「사이드 패널 열기」** 버튼이 알아서 켭니다.

## 어사이드 비용신청 (이 포크에서 추가)

1. 대시보드 **「통합 DATA 시트」**에서 평소처럼 수금까지 확인합니다.
2. **「HRD-Net 비용신청 올리기」**를 누르면 수금 확인된 회차가 `rpa` 엔진의 inbox로 내보내지고, 증빙 폴더에 `회차 > 업체` 빈 폴더가 만들어집니다.
   ```
   inbox/증빙/<과정명>_<N>회차/<업체명>/전자계산서_<업체명>_<N>회차.pdf
                                        /수납확인서_<업체명>_<N>회차.pdf
   ```
3. 업체 폴더마다 **전자계산서·수납확인서 2개**를 넣습니다. 넣으면 몇 초 안에 탭에서 그 업체가 **신청가능**이 됩니다(「정리」를 다시 누를 필요 없음).
4. **「HRD-Net 비용신청」 탭**에서 회차를 펼쳐 업체를 체크합니다(신청가능만 체크됨). **「50개 선택」「100개 선택」**으로 한 번에 고를 수 있습니다.
   - 업체마다 **상태 콤보**(신청완료 · 신청가능 · 불가)가 있습니다. 미납 등으로 이번에 못 하는 업체는 `불가` + 사유를 적어 두면 다음 신청 때 다시 `신청가능`으로 바꿔 돌립니다.
   - 맨 오른쪽 **▸**를 누르면 그 업체의 세로 현황(어떤 매크로로, 어느 단계까지 갔는지 — 여분 필드 f01~f30)이 나옵니다.
5. 아래 **매크로**를 고르고 모의 실행 / 점검 / 미리 채워 보기 / 신청을 실행합니다. 진행과 질문은 오른쪽 사이드 패널에 나옵니다.
   - 한 회차가 끝나면 HRD-Net 검색화면(최초 입력 단계)으로 돌아가 다음 회차를 이어서 합니다.
   - 업체 하나가 미납·체납·업체명 확인 불가면 그 업체만 `불가`로 빼고 계속합니다. 건너뛴 이유는 「확인요청 목록」(`status/질문목록.md`)에 모입니다.
6. 로그인·인증서와 마지막 `[훈련비용 신청]`은 사람이 합니다. 최종 신청은 회차마다 패널에서 확인합니다.
7. **「4 결과표」**로 결과를 만들고, 대시보드의 **「결과 반영」**으로 비용신청여부를 일괄 체크합니다.
8. **「백업·정리」**로 끝난 회차를 백업 폴더로 옮기고, 탭 아래 **「백업 보관함」**에서 목록을 봅니다. 보관 기간(기본 90일)이 지난 백업은 자동 삭제되며, `archive_root`를 정하면 장기 보관처로 복사가 끝난 것만 삭제됩니다.

### 매크로 (자동화 늘리기)
- 매크로 하나 = `rpa/macros/<id>/` 폴더 하나(`macro.yaml` · `steps.yaml` · `templates/learned/` · `learned_actions.json`).
- 지금 쓰는 것: **HRD-Net 위탁 비용신청 v1(기본)** (`hrd-wituk-claim-v1`).
- 새 매크로 만들기: 탭 아래 **「＋ 새 매크로」** → 기본 매크로가 복사되어 `시험중`으로 생깁니다(시험중이면 [신청] 잠김).
  → 업체 1곳만 체크하고 **「학습 미리채워 보기」**(모든 단계를 사람이 누르며 클릭 녹화) → **「미리 채워 보기」**로 사람 단계가 줄었는지 확인 → **「사용 승격」**.

### 창 배치
- 모니터 2개(가로형): 작업 모니터에 HRD-Net(왼쪽)+사이드 패널(오른쪽), 대시보드는 다른 모니터.
- 모니터 1개: 한 화면에 HRD-Net(왼쪽 약 65%) · 패널(오른쪽 위) · 대시보드 축소 보기(오른쪽 아래).
- 「사이드 패널 열기」·「창 다시 배치」를 누를 때 배치합니다. 패널은 하나만 뜨고, 실행 중 HRD-Net 창이 최대화되면 제자리로 되돌립니다.

설정은 `rpa/local.json`(처음 켜면 자동 생성)에서 바꿉니다: `data_root`, `backup_root`, `backup_keep_days`, `archive_root`, `hrdnet_exe`, `macro`, `layout`(auto|single|dual), `work_display`(HRD-Net을 둘 모니터 번호).
