# HRD-Net 비용신청 자동화 (v2.2.8) — 사용 요약 · 문제 신고 양식

문제가 생기면 이 파일 맨 아래 **요청 양식**을 채워 **정현진 대리**께 메일로 보내 주세요.
대리님이 먼저 확인하시고, 풀리지 않으면 이돈우(AX센터)에게 전달합니다.

---

## 1. 이 프로그램이 하는 일
- 대시보드에서 고른 업체를 **1곳씩** 처리합니다.
  - 순서: HRD-Net [신청] → 비용등록(업체·훈련생 체크 → 산출액 → 저장) → 증빙 첨부 → 상단 [저장]
- 저장되면 비용신청관리(위탁) 목록에 **「정상지급(작성중)」** 행이 생깁니다.
- **고용보험확인 · 훈련비용 신청은 손으로** 합니다(프로그램이 누르지 않음).

## 2. 쓰는 순서
1. GitHub ZIP 받기 → 새 폴더에 풀기 → 기존 PC의 `rpa\local.json` 복사 → `setup.bat` → `run.bat`
   - 위쪽에 v2.2.8이 보이면 됩니다.
2. HRD-Net 로그인 → 첫 화면에 둡니다. 비용신청 탭 → [사이드 패널 열기]
3. 증빙 폴더의 회차 > 업체 폴더에 증빙(전자계산서·수납확인서)을 넣습니다. 몇 초 뒤 업체가 「신청가능」으로 바뀝니다.
4. 회차(또는 업체)를 체크 → **[▶ 신청 (업체별 저장)]** → 끝날 때까지 손대지 않습니다.
5. 끝나면 업체 상태가 「저장완료」로 바뀝니다. 결과표(`결과\결과_날짜.xlsx`)는 자동으로 만들어집니다.
6. 고용보험확인 · 훈련비용 신청은 손으로 합니다.

> **PC가 바뀌면**
> - 디스플레이 배율은 100%로 둡니다.
> - 창 배치는 [사이드 패널 열기]가 해 주는 대로 둡니다(HRD-Net 왼쪽 · 패널 오른쪽).
> - **첫 실행은 신청가능 1곳인 회차로** 해 보고, 잘 되면 늘립니다.
>
> [미리 채워 보기]는 업체 1곳을 채워 보여 주기만 하고 저장하지 않습니다.

## 3. 문제가 생기면 먼저 볼 것

| 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| 업체가 「불가」 | 그 업체만 빠지고 나머지는 계속 진행됨 | 결과표 맨 앞 「업체」 시트의 **이유**를 보고, 그 업체만 HRD-Net에서 손으로 처리합니다. 처리한 뒤에는 비용신청 탭 상태 콤보를 「저장완료」(또는 「신청완료」)로 바꿉니다 |
| 패널에 「멈춤」·「중단」 | 진행이 멈춤 | HRD-Net 화면은 그대로 두고, 그 업체 신청서 상태를 확인한 뒤 아래 양식으로 요청합니다 |
| 「비용등록만 저장되고 상단 [저장] 전에 멈췄습니다」 | 나머지 업체는 하지 않고 멈춤 | 그 업체를 손으로 마무리하거나 지운 뒤 다시 실행합니다. 원인은 양식으로 요청합니다 |
| 업체에 「PDF 3개 (2개여야 함)」 — 첨부가 3개인 과정 | 세 번째 첨부 행이 아직 설정되지 않음 | 업체 1곳을 손으로 저장한 뒤 「첨부파일 목록」 화면을 캡처해 양식에 붙입니다. 설정 전에는 프로그램이 2개만 붙이고 저장하지 않도록 막혀 있습니다 |

자주 나오는 「불가」 이유:
- 사업장관리번호가 다름
- 미납·체납 등으로 HRD-Net에서 그 업체가 비활성
- 훈련인원 오류여부 Y
- 증빙 누락

손으로 처리한 업체는 **반드시 상태를 바꿔** 두세요. 「저장완료」·「신청완료」·「불가」 업체는 프로그램이 다시 돌리지 않습니다.

## 4. 요청 양식 (복사해서 메일 본문에 채워 주세요)

```
받는 사람: 정현진 대리
제목: [비용신청 자동화 문제] (과정명) (N)회차 · (업체명) · (MM/DD)

1. 보낸 사람 / 날짜·시각   :
2. 과정명 · 회차           :
3. 업체명(여러 곳이면 모두) :
4. 누른 버튼               : [▶ 신청 (업체별 저장)] / [미리 채워 보기]
5. 패널의 마지막 문구       : (그대로 복사)
6. 결과표 「업체」 시트     : 상태 =      / 멈춘 단계 =      / 이유 =
7. HRD-Net 상태            :
   - 「정상지급(작성중)」 행이 생겼나요?      예 / 아니오
   - 비용등록만 저장되고 상단 [저장]은 안 됐나요?  예 / 아니오 / 모름
   - 손으로 마무리하거나 지웠나요?           마무리 / 지움 / 그대로 둠
8. 첨부 (체크)
   [ ] 사이드 패널 [보낼 파일 만들기] zip
   [ ] 화면 녹화 (가능하면)
   [ ] 결과표 (결과\결과_날짜.xlsx)
   [ ] (첨부 3개 과정이면) 업체 1곳을 손으로 저장한 「첨부파일 목록」 화면 캡처
9. 한 줄 메모               :
```

- 훈련생 이름이 보일 수 있으니 **사내 메일로만** 보내 주세요.
- 정현진 대리님이 풀지 못하면 이 메일을 그대로 이돈우(AX센터)에게 전달해 주세요.

## 5. 신청까지 자동으로
- 쓰시다가 첨부와 저장이 안정적이라고 판단되면, 정현진 대리님을 통해 「신청까지 해 달라」고 요청해 주세요.
- 요청을 받으면 [고용보험확인] → [훈련비용 신청]까지 이어서 하도록 바꿉니다.
- 그 전까지는 프로그램이 두 버튼을 누르지 않습니다.
