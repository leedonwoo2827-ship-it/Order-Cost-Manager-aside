### 멈춘 이유 (녹화 00:20)
- [저장] 뒤에 **「Alert — 비용신청 가능한 참여업체가 존재하지 않습니다.」** 창이 떴습니다.
  - 말씀하신 대로 **비용등록을 먼저 해야 저장이 됩니다.**
  - 이 창은 제목이 영어 「Alert」입니다. 「Confirm」·「알림」 창만 알던 프로그램이 이 창을 보지 못하고 「확인창이 없다」고 멈췄습니다.

## 2. 바뀐 점 (v2.2.5)
1. **【비용등록 → 업체 체크 → 훈련생 체크 → 산출액 → 저장】을 다시 넣었습니다.**
   - [신청] 뒤 화면을 조금 내려 [비용등록]이 보이면 누릅니다. 지난번 이 단계가 멈춘 것은 버튼이 화면 아래에 가려 있었기 때문입니다.
   - 진행 순서
     - 업체: 사업장관리번호가 같은 줄만 체크
     - 훈련생: 전체 체크 전에 오류여부 Y를 확인
     - [산출액→신청액] → 금액 확인 → [저장] → 확인 2번 → 창 닫기
2. 그다음 화면을 내려 **증빙 2개 첨부 → 상단 [저장] → 확인 2번**까지 합니다.
3. **[고용보험확인]은 하지 않습니다.** [훈련비용 신청]도 대리님이 직접 누르시면 됩니다.
4. 「Alert」 창도 읽고 [확인]을 누릅니다. 오류 문구(예: 참여업체가 존재하지 않습니다)면 그 문구를 남기고 멈춥니다.

## 3. 설치 (지난번과 같음)
1. https://github.com/leedonwoo2827-ship-it/Order-Cost-Manager-aside → 녹색 [Code] → [Download ZIP]
2. 새 폴더에 풀기
3. 예전 폴더의 `rpa\local.json`을 새 폴더 rpa 안에 복사
4. `setup.bat` 한 번 → 그다음부터 `run.bat`
5. 위쪽에 **v2.2.5**가 보이면 새 버전입니다.

※ HRD-Net이 떠 있는 모니터의 배율은 100%로 그대로 두세요.

## 4. 테스트 — 미리 채워 보기 1곳 (10분, 녹화)
1. HRD-Net을 **첫 화면**에 둡니다.
2. 비용신청 탭에서 **10회차 포커스타임 1곳**만 체크하고 [미리 채워 보기]를 누릅니다. 손대지 않습니다.
3. 기대하는 순서
   - 메뉴 → 과정명·회차 → 검색 → 10회차 [신청]
   - 화면 조금 내림 → [비용등록] → 업체 체크 → [비용등록] → 비용등록 창 최대화 → 훈련생 체크 → [산출액→신청액] → [저장] → 확인 2번 → 창 닫기
   - 화면 아래로 → 첨부 2개 → 상단 [저장] → 확인 2번 → 끝
4. 끝나면 HRD-Net 화면에서 두 가지를 봐 주세요.
   - 「참여업체별 비용신청 현황」에 포커스타임이 들어갔는지
   - 첨부 2개가 저장됐는지

> 녹화 중 마우스는 HRD-Net 바깥(오른쪽 패널 쪽)에 두세요.
