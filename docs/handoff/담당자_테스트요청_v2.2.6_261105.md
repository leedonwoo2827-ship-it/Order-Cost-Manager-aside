# 비용신청 자동화 v2.2.6 — [비용등록] 찾기 수정 + 재테스트 요청 (11/5)

## 1. 11/5 테스트 결과
| 단계 | 결과 |
|---|---|
| 메뉴 → 과정명·회차 → 검색 → 10회차 [신청] | 자동 성공 |
| 화면 조금 내림 → [비용등록] | 멈춤 (「아래로 내려도 찾는 칸이 보이지 않습니다」) |

### 멈춘 이유 (녹화 00:16)
- 대리님 PC의 HRD-Net은 **마우스 휠을 한 번만 굴려도 화면이 맨 위에서 맨 아래까지 한 번에 내려갑니다.**
- [비용등록] 버튼(「참여업체별 비용신청 현황」 오른쪽 위)은 화면 가운데쯤까지만 내렸을 때 보입니다.
- 휠이 그 자리를 건너뛰어서, 프로그램이 버튼을 한 번도 보지 못하고 멈췄습니다.
- 11/4 녹화도 똑같이 한 번에 맨 아래로 갔습니다. 그때는 맨 아래의 첨부파일 목록을 찾는 단계라 문제가 없었습니다.

## 2. 바뀐 점 (v2.2.6)
1. **휠 대신 스크롤바의 ▼ 버튼을 한 번씩 누릅니다.**
   - HRD-Net 화면 오른쪽 끝 스크롤바 맨 아래의 작은 ▼입니다.
   - 한 번 누를 때마다 [비용등록]이 보이는지 확인하고, 보이면 바로 멈춰서 누릅니다.
   - ▼가 안 들으면 스크롤바 빈 곳을 눌러 한 화면씩 내립니다. 그래도 없으면 ▲로 올라가며 다시 찾습니다.
   - 끝까지 못 찾으면 지금처럼 이유를 남기고 멈춥니다. 다른 곳을 누르지 않습니다.
2. 그 뒤 순서는 v2.2.5와 같습니다.
   - 비용등록: 업체 체크 → 훈련생 체크 → [산출액→신청액] → [저장] → 확인 → 창 닫기
   - 첨부: 화면 아래로 → 첨부 2개 → 상단 [저장] → 확인 2번 → 끝
3. [고용보험확인]·[훈련비용 신청]은 하지 않습니다(대리님이 직접).
4. 새 캡처는 필요 없습니다. ▼·▲ 그림은 보내 주신 녹화에서 잘랐습니다.

## 3. 설치 (지난번과 같음)
1. https://github.com/leedonwoo2827-ship-it/Order-Cost-Manager-aside → 녹색 [Code] → [Download ZIP]
2. 새 폴더에 풀기
3. 예전 폴더의 `rpa\local.json`을 새 폴더 rpa 안에 복사
4. `setup.bat` 한 번 → 그다음부터 `run.bat`
5. 위쪽에 **v2.2.6**이 보이면 새 버전입니다.

※ 화면 배치(HRD-Net 왼쪽 · 사이드 패널 오른쪽)와 배율 100%는 그대로 두세요. 창 크기를 바꾸지 않습니다.

## 4. 테스트 — 미리 채워 보기 1곳 (10분, 녹화)
1. HRD-Net을 **첫 화면**에 둡니다.
2. 비용신청 탭에서 **10회차 포커스타임 1곳**만 체크하고 [미리 채워 보기]를 누릅니다. 손대지 않습니다.
3. 기대하는 순서
   - 메뉴 → 과정명·회차 → 검색 → 10회차 [신청]
   - **스크롤바 ▼를 여러 번 톡톡 누름 → [비용등록]이 보이면 멈춤**
   - [비용등록] → 업체 체크 → [비용등록] → 비용등록 창 최대화 → 훈련생 체크 → [산출액→신청액] → [저장] → 확인 → 창 닫기
   - 화면 아래로 → 첨부 2개 → 상단 [저장] → 확인 2번 → 끝
4. 끝나면 HRD-Net 화면에서 두 가지를 봐 주세요.
   - 「참여업체별 비용신청 현황」에 포커스타임이 들어갔는지
   - 첨부 2개가 저장됐는지

> 녹화 중 마우스는 HRD-Net 바깥(오른쪽 패널 쪽)에 두세요.
