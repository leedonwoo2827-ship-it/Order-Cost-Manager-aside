# 비용신청 자동화 v2.2.7 — 1곳 끝까지 → 바로 2~3곳 테스트 요청 (11/5)

## 목표와 이번 테스트
- 목표는 **한 회차의 여러 업체를 한 번에 끝까지** 처리하는 것입니다.
- 지금까지는 단계마다 오류가 나서 1곳으로 하나씩 확인했습니다.
- 이번에는 순서대로 두 가지를 봅니다.
  1. **1곳을 끝까지** — 첨부 2개 → 상단 [저장]까지
  2. 통과하면 **바로 이어서 2~3곳**을 한 번에

## 2. 고친 것 (v2.2.7)
1. **첨부파일 목록으로 못 내려간 문제 (13:09)**
   - 비용등록 창을 닫고 돌아오면 마우스 휠을 굴려도 화면이 내려가지 않았습니다.
   - 이제 이 단계도 스크롤바 ▼를 눌러 맨 아래까지 내립니다.
   - 비용등록을 하면 위쪽 버튼이 늘어나 [저장] 자리가 옮겨지는데, 그 화면에서도 ▼를 찾도록 맞췄습니다. 둘째 업체부터도 같은 화면입니다.
2. **참여 업체 목록에서 포커스타임을 못 찾은 문제 (11:49)**
   - 마우스 포인터가 업체 줄의 체크칸을 가리면, 프로그램이 그 줄을 보지 못했습니다.
   - 이제 목록을 읽기 전에 포인터를 비켜 두고, 목록이 다 뜰 때까지 기다렸다가 읽습니다.
3. 새 캡처는 필요 없습니다. 보내 주신 녹화로 확인했습니다.

## 3. 설치 (지난번과 같음)

## 4. 테스트 (20분, 녹화)

### 준비
- 말씀하신 대로 10회차 포커스타임 비용등록을 지워 처음 상태로 둡니다.
- 「참여업체별 비용신청 현황」에서 포커스타임이 빠졌는지 봅니다.
- HRD-Net을 첫 화면에 둡니다. 녹화를 켜고, 마우스는 HRD-Net 바깥(오른쪽 패널 쪽)에 둡니다.

### 테스트 1 — 1곳 끝까지 (10분)
- 비용신청 탭에서 **10회차 포커스타임 1곳**만 체크 → [미리 채워 보기]. 끝날 때까지 손대지 않습니다.
- 기대하는 순서
  - 메뉴 → 과정명·회차 → 검색 → 10회차 [신청]
  - 스크롤바 ▼ → [비용등록] → 업체 체크 → 훈련생 체크 → [산출액→신청액] → [저장] → 창 닫기
  - **스크롤바 ▼를 여러 번 눌러 맨 아래로** → 첨부 2개 → 상단 [저장] → 확인 2번 → 끝
- 끝나면 HRD-Net에서 확인합니다.
  - [ ] 「참여업체별 비용신청 현황」에 포커스타임이 들어갔는지
  - [ ] 첨부 2개가 저장됐는지

### 테스트 2 — 바로 이어서 2~3곳 (10분)
테스트 1이 끝까지 되면 같은 자리에서 바로 합니다.
- HRD-Net을 첫 화면에 둡니다.
- 비용신청 탭에서 **10회차의 다른 업체 2~3곳**을 체크합니다. 아직 손으로 처리하지 않은 업체로 고릅니다. 포커스타임은 빼고 [미리 채워 보기]를 누릅니다.
- 기대하는 순서: 업체마다 [비용등록] → 업체 체크 → 훈련생 체크 → 산출액 → [저장] → 창 닫기를 반복 → 맨 아래로 → 첨부 → 상단 [저장] → 끝
- 끝나면 HRD-Net에서 확인합니다.
  - [ ] 「참여업체별 비용신청 현황」에 고른 업체가 모두 들어갔는지
  - [ ] 첨부가 업체 수만큼 저장됐는지

> 업체 하나에 문제가 있으면 프로그램이 그 업체만 빼고 이유를 남깁니다. 패널에 나온 문구를 메모해 주세요.
